# 高難度地形の歩行を二つの指標で読む

二足歩行制御器の開発評価800エピソードのうち、Hardcore環境で記録した200件を取り出した。Standard PPOとRobust PPOは各5学習seed、各方式100エピソードである。報酬は割引をかけないエピソード合計、ステップ数は終了までの長さを示す。

| 指標 | Standard PPO | Robust PPO |
|---|---:|---:|
| 平均報酬 | −82.44 | −80.41 |
| 報酬の中央値 | −88.20 | −83.97 |
| 平均ステップ数 | 416.27 | 613.50 |
| 報酬が−90未満 | 44 / 100 | 32 / 100 |
| 報酬が300超 | 0 / 100 | 0 / 100 |

Robustの試行は平均で約197ステップ長く続いたが、平均報酬の差は約2点だった。長く続くことと、高い報酬を得ることは、この条件では一致しなかった。元の記録には転倒・ゴールの内訳がないため、終了フラグから転倒率や踏破率は算出できない。

集計元は2026年10月31日のDevelopment評価を収録したStudio v0.9の解析資料。ここで比較したのは開発用データであり、最終性能の評価には用いていない。
